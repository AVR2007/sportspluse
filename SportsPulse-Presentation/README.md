# SportsPulse: Interactive project review (terminal style)
Run (offline, no backend): double-click index.html  (or: python3 -m http.server 8000, then open http://localhost:8000)
Edit team / guide / section / year: open config.js (the only place names live).
Keys: Left/Right/Space move, Home/End, 1-7 jump, F fullscreen, L live demo, Esc close.
Files: index.html, style.css, script.js, config.js
